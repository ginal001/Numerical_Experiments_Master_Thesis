This repository contains examples developed for a Master's thesis at the University of Warsaw (academic year 2025/2026). The work extends [stochastic interpolants](https://arxiv.org/abs/2303.08797) by embedding them into a [fibered Wasserstein space](https://arxiv.org/abs/2203.08104).

### Setup

This project uses [uv](https://docs.astral.sh/uv/) for dependancy managment. With `uv` installed (recommended), set up the environment and dependencies by running:
